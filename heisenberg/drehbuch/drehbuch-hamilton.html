Szene 1

Vom Operator zur Matrix

Erklärung, anschaulich

Ein Computer kann mit \(H|\psi\rangle\) nichts anfangen, er braucht Zahlen. Wir wählen eine Basis und fragen für jedes Paar von Basiszuständen: Wie viel von \(|m\rangle\) steckt in \(H|n\rangle\)? Diese Zahlen bilden eine Tabelle, die Hamilton-Matrix.

Tafel · 2.2 S. 5 \[\begin{aligned} &\mathbf{1} = \sum_n |n\rangle\langle n| \ \text{einschieben, von links } \langle m|\,\cdot\\ &\sum_n \underbrace{\langle m|H|n\rangle}_{(\bar H)_{mn}}\,\underbrace{\langle n|\psi\rangle}_{(\vec\psi)_n} = E\,\underbrace{\langle m|\psi\rangle}_{(\vec\psi)_m} \qquad (*)\\ &\Rightarrow\quad \boxed{(\bar H)_{mn} = \langle m|H|n\rangle},\qquad \boxed{\bar H\vec\psi = E\vec\psi} \end{aligned}\]
Die eigentliche Frage

Das Skript fasst es selbst zusammen: „How to set up the Hamilton matrix?“ Von Hand geht es nur für sehr kleine Cluster (\(N=2\): \(4\times4\)). Für alles andere brauchen wir ein Programm.

Frage
  1. Wo genau wird benutzt, dass die Basis vollständig ist?
  2. Welcher Index von \((\bar H)_{mn}\) gehört zum Zustand, auf den \(H\) wirkt?
Lösung
  1. Beim Einschieben von \(\mathbf{1} = \sum_n|n\rangle\langle n|\). Ohne Vollständigkeit wäre das nicht die Eins.
  2. Der Spaltenindex \(n\). \(H|n\rangle\) ist die \(n\)-te Spalte. Darum schreibt der Code später in H[l, n]: Zeile \(l\), Spalte \(n\).
Szene 2

Die Binärbasis

Erklärung, anschaulich

Jeder Spin ist ein Bit: oben = 1, unten = 0. Eine Konfiguration aller Spins ist dann eine Binärzahl, und die Zahl ist das Label des Zustands. So wird aus \(|{\uparrow\downarrow\uparrow\uparrow}\rangle\) einfach \(13\).

Tafel · 2.1 S. 2 \[\begin{aligned} &|{\uparrow}\rangle_i \mathrel{\hat=} |1\rangle_i \ \to\ z_i = 1,\qquad |{\downarrow}\rangle_i \mathrel{\hat=} |0\rangle_i \ \to\ z_i = 0\\ &[n]_{10} = [z_N \dots z_2\, z_1]_2\\ &\boxed{n = \sum_{i=1}^{N} z_i\, 2^{\,i-1}},\qquad n = 0,1,\dots,2^N-1 \end{aligned}\]
Achte auf: die Lesefalle

Im Ket steht Platz 1 links, in der Binärzahl steht Platz 1 rechts. \(|{\uparrow\downarrow\uparrow\uparrow}\rangle\) hat \((z_1,z_2,z_3,z_4) = (1,0,1,1)\), die Binärzahl ist aber \([1101]_2 = 13\). Wer einfach „1011“ abliest, landet bei \(11\) und rechnet mit dem falschen Zustand.

Szene 3

Der x-Link: beide Spins kippen

Erklärung, anschaulich

Der Hamiltonian ist eine Summe von Links \(J^\alpha_{pq}S^\alpha_pS^\alpha_q\). Statt \(H\) als Ganzes anzufassen, schauen wir, was ein Link mit einem Basiszustand macht. \(S^x\) kippt einen Spin, \(S^x_pS^x_q\) kippt also beide Spins \(p\) und \(q\). Herauskommt wieder genau ein Basiszustand \(|l\rangle\).

Tafel · 2.2 S. 6 \[J^x_{pq}S^x_pS^x_q|n\rangle = \tfrac14 J^x_{pq}\left(S^+_pS^+_q + S^+_pS^-_q + S^-_pS^+_q + S^-_pS^-_q\right)|\dots z_p\dots z_q\dots\rangle\] \[\to\ \text{nur einer der vier Terme ist } \neq 0\]
Herleitung der Flip-Regel, Schritt für Schritt
  1. Kippen von Platz \(p\) ändert \(z_p\) und damit den Beitrag \(z_p\,2^{p-1}\) zu \(n\).
  2. War \(z_p=0\) (\(\downarrow\to\uparrow\)), kommt \(2^{p-1}\) dazu. War \(z_p=1\) (\(\uparrow\to\downarrow\)), fällt \(2^{p-1}\) weg.
  3. Beide Fälle in einer Formel: \((1-2z_p) = +1\) für \(z_p=0\) und \(-1\) für \(z_p=1\).
  4. Für Platz \(q\) genauso, und die Änderungen addieren sich.
Tafel · 2.2 S. 7, Gl. (*) \[\boxed{\,l = n + (1-2z_p)\,2^{p-1} + (1-2z_q)\,2^{q-1}\,}\qquad (*)\] \[J^x_{pq}S^x_pS^x_q|n\rangle = \tfrac14 J^x_{pq}|l\rangle \quad\Rightarrow\quad \langle m|J^x_{pq}S^x_pS^x_q|n\rangle = \tfrac14 J^x_{pq}\,\delta_{ml}\]
Frage
  1. Warum ist bei \(S^x_pS^x_q\) immer genau einer der vier Terme ungleich null?
  2. Wie viele von null verschiedene Matrixelemente erzeugt ein einziger x-Link in der ganzen Matrix?
Lösung
  1. Auf Platz \(p\) wirkt nur der Operator, der zu \(z_p\) passt: \(S^+\) bei \(\downarrow\), \(S^-\) bei \(\uparrow\). Der andere gibt null. Für \(q\) genauso. Von \(2\cdot2\) Kombinationen bleibt genau eine.
  2. Für jedes \(n\) genau eins, also \(2^N\) Elemente. 2.2 S. 7 unten
Selbst rechnen

\(N=4\), \(n=13\), Link \(J^x_{23}S^x_2S^x_3\). Bestimme \(l\) mit Gl. (*) und schreibe \(|l\rangle\) als Ket. Kontrolle: Spins 2 und 3 müssen gekippt sein.

Lösung

\((z_1,z_2,z_3,z_4)=(1,0,1,1)\), also \(z_2=0,\ z_3=1\).

\[l = 13 + (1-0)\cdot2^1 + (1-2)\cdot2^2 = 13+2-4 = 11\]

\(11 = [1011]_2 \ \Rightarrow\ (z_1,z_2,z_3,z_4) = (1,1,0,1) \ \Rightarrow\ |{\uparrow\uparrow\downarrow\uparrow}\rangle\). Spins 2 und 3 sind gekippt. ✓ 2.2 S. 6–7

Szene 4

Der y-Link: derselbe Flip, aber ein Vorzeichen

Erklärung, anschaulich

\(S^y\) kippt ebenfalls, also landet der y-Link beim selben \(|l\rangle\) wie der x-Link. Das \(\tfrac1i\) in \(S^y = \tfrac{1}{2i}(S^+-S^-)\) quadriert sich zu \(-\tfrac14\). Dazu kommen Minuszeichen innerhalb der Klammer. Je nach Konfiguration bleibt ein Vorzeichen \(s\) übrig.

Tafel · 2.2 S. 8 \[J^y_{pq}S^y_pS^y_q|n\rangle = -\tfrac14 J^y_{pq}\left(S^+_pS^+_q - S^+_pS^-_q - S^-_pS^+_q + S^-_pS^-_q\right)|n\rangle = s\cdot\tfrac14 J^y_{pq}\,|l\rangle\] \[s = \begin{cases} +1 & z_p \neq z_q\\ -1 & z_p = z_q\end{cases}\qquad\Rightarrow\qquad \boxed{\,s = -(2z_p-1)(2z_q-1)\,}\]
Selbst rechnen

Leite \(s\) selbst her: Welcher der vier Terme überlebt bei \(z_p\neq z_q\), welcher bei \(z_p=z_q\)? Welches Vorzeichen hat er in der Klammer? Multipliziere mit dem \(-\tfrac14\) davor.

Hinweis

Bei antiparallelen Spins überlebt ein „gemischter“ Term \(S^+S^-\) oder \(S^-S^+\), bei parallelen ein „gleicher“ Term \(S^+S^+\) oder \(S^-S^-\).

Lösung
\[\begin{aligned} z_p\neq z_q:&\quad \text{gemischter Term, Klammer } (-1)\ \Rightarrow\ \left(-\tfrac14\right)(-1) = +\tfrac14\ \Rightarrow\ s=+1\\ z_p = z_q:&\quad \text{gleicher Term, Klammer } (+1)\ \Rightarrow\ -\tfrac14\ \Rightarrow\ s=-1 \end{aligned}\]

Prüfung: \(z_p=z_q \Rightarrow (2z_p-1)(2z_q-1)=+1 \Rightarrow s=-1\) ✓. \(z_p\neq z_q \Rightarrow\) Produkt \(-1 \Rightarrow s=+1\) ✓.

Gegenprobe: was passiert, wenn s fehlt?

Beim Heisenberg-Modell stehen x- und y-Link mit gleichem \(J\) nebeneinander. Mit \(s\) heben sie sich bei parallelen Spins auf (\(\tfrac14-\tfrac14=0\)), also gibt es kein \(|{\uparrow\uparrow}\rangle\to|{\downarrow\downarrow}\rangle\). Bei antiparallelen Spins addieren sie sich zu \(\tfrac12 J\), das ist der Spin-Austausch \(\tfrac12 J(S^+_pS^-_q + S^-_pS^+_q)\). Ohne \(s\) würde fälschlich \(|{\uparrow\uparrow}\rangle\leftrightarrow|{\downarrow\downarrow}\rangle\) gekoppelt. Die Matrix wäre zwar noch symmetrisch, aber das Spektrum falsch, und \(S^z_\text{tot}\) wäre nicht mehr erhalten. Vergleiche 2.2 S. 10, XXZ-Modell.

Szene 5

Der z-Link: nur die Diagonale

Erklärung, anschaulich

\(S^z\) kippt nichts, es misst nur. Die Basiszustände sind Eigenzustände von \(S^z_p\) und \(S^z_q\), also bleibt \(|n\rangle\) stehen. Es kommt nur eine Zahl heraus: \(+\tfrac14\) bei parallelen, \(-\tfrac14\) bei antiparallelen Spins.

Tafel · 2.2 S. 8 \[\begin{aligned} S^z_p|n\rangle &= \tfrac12(2z_p-1)\,|n\rangle\\ J^z_{pq}S^z_pS^z_q|n\rangle &= \tfrac14 J^z_{pq}\,(2z_p-1)(2z_q-1)\,|n\rangle\\ \langle m|J^z_{pq}S^z_pS^z_q|n\rangle &= \tfrac14 J^z_{pq}\,(2z_p-1)(2z_q-1)\,\delta_{mn} \end{aligned}\] \[\Rightarrow\ \text{z-Links geben nur Diagonalelemente } (\bar H)_{nn}\]
Frage
  1. Warum gilt \(2z_p-1 = \pm1\) genau für \(\uparrow\) bzw. \(\downarrow\)?
  2. Welche Links gibt es beim Ising-Modell, und welche Form hat seine Matrix deshalb?
Lösung
  1. \(z_p=1 \to 2\cdot1-1=+1\) (also \(S^z=+\tfrac12\)), \(z_p=0\to-1\) (also \(S^z=-\tfrac12\)).
  2. Nur z-Links, also ist die Matrix diagonal. Die Eigenwerte stehen direkt auf der Diagonale. Das ist Aufgabe 1b, dort stellst du diese Diagonalmatrix von Hand auf.
Szene 6

Der Code: Schleife über n, Schleife über Links

Codestruktur · 2.2 S. 9 \[\begin{aligned} &\textbf{for } n = 0 \dots 2^N-1 &&\text{(Basiszustände)}\\ &\quad [n]_{10}\to[z_N\dots z_1]_2\\ &\quad \textbf{for } j = 1\dots L &&\text{(Links)}\\ &\qquad \textbf{if } \alpha = x \text{ oder } y: && l \text{ nach (*)},\ \ \bar H_{ln} \mathrel{+}= \tfrac14 J^x_{pq}\ \text{bzw.}\ s\,\tfrac14 J^y_{pq}\\ &\qquad \textbf{else } (\alpha=z): && \bar H_{nn} \mathrel{+}= \tfrac14 J^z_{pq}(2z_p-1)(2z_q-1) \end{aligned}\]

Keine Doppelschleife über \(n\) und \(m\) nötig!

Achte auf: das Minus aus H = −Σ … (vermutete Ungenauigkeit im Skript)

Der Kasten auf S. 9 nennt die Matrixelemente des Terms \(J^\alpha_{pq}S^\alpha_pS^\alpha_q\). Der Hamiltonian ist aber \(H = -\sum J^\alpha_{ij}S^\alpha_iS^\alpha_j\). Es muss also \(-\tfrac14 J\) addiert werden, nicht \(+\tfrac14 J\). Die Musterlösung macht es richtig (H[...] -= 0.25*J), die Python-Vergleichsbearbeitung auch. Wer den Kasten wörtlich abtippt, bekommt \(-\bar H\), also ein gespiegeltes Spektrum: Grundzustand und höchster Zustand vertauscht.

Selbst programmieren

Schreibe hamilton_matrix(N, links). Jeder Link ist ein Tupel (alpha, p, q, J) mit alpha \(\in\{x,y,z\}\) und Plätzen \(p,q\in\{1,\dots,N\}\) wie im Skript. Rückgabe: die \(2^N\times2^N\)-Matrix als numpy-Array.

Hinweis 2 · Vorzeichen

Jeder Beitrag bekommt ein Minus aus \(H=-\sum\dots\):

\[\text{x: } -\tfrac14 J,\qquad \text{y: } -s\,\tfrac14 J,\qquad \text{z: } -\tfrac14 J\,(2z_p-1)(2z_q-1)\]

Und +=, nicht =, weil mehrere Links auf dasselbe Element schreiben können.

Hinweis 3 · Links für das Heisenberg-Modell

Jedes Paar \(\langle ij\rangle\) bekommt drei Links: x, y und z mit demselben \(J\). Beim Dreieck also \(3\times3 = 9\) Links, wie L = 9 in der Musterlösung.

Lösung · Referenzcode (getestet)
import numpy as np

def hamilton_matrix(N, links):
    """Hamilton-Matrix für H = -sum J^a_pq S^a_p S^a_q.
    links: Liste von (alpha, p, q, J), alpha in 'xyz', Plätze p, q = 1..N."""
    dim = 2**N
    H = np.zeros((dim, dim))
    for n in range(dim):                                  # Schleife über Basiszustände
        z = [(n >> (i-1)) & 1 for i in range(1, N+1)]     # z[i-1] = z_i
        for alpha, p, q, J in links:                      # Schleife über Links
            zp, zq = z[p-1], z[q-1]
            if alpha in 'xy':
                l = n + (1-2*zp)*2**(p-1) + (1-2*zq)*2**(q-1)   # Gl. (*), S. 7
                s = 1 if alpha == 'x' else -(2*zp-1)*(2*zq-1)    # Vorzeichen, S. 8
                H[l, n] += -0.25 * J * s                  # Minus aus H = -sum ...
            else:                                         # z-Link: diagonal
                H[n, n] += -0.25 * J * (2*zp-1) * (2*zq-1)
    return H

def heisenberg_links(pairs, J=1.0):
    """isotropes Heisenberg-Modell: je Paar ein x-, y- und z-Link"""
    return [(a, p, q, J) for p, q in pairs for a in 'xyz']
Szene 7

Teil b: Eigenenergien

Selbst rechnen, erst von Hand: N = 2

\(H = -J\,\vec S_1\cdot\vec S_2\). Stelle die \(4\times4\)-Matrix in der Basis \(n=0,1,2,3\) auf und bestimme die Eigenwerte. Dann mit dem Code prüfen.

Hinweis
\[\vec S_1\cdot\vec S_2 = \tfrac12\left(S^+_1S^-_2 + S^-_1S^+_2\right) + S^z_1S^z_2\]

Die Zustände \(0=|{\downarrow\downarrow}\rangle\) und \(3=|{\uparrow\uparrow}\rangle\) werden nicht gekippt. Der mittlere \(2\times2\)-Block hat die Eigenvektoren \(\tfrac{1}{\sqrt2}(1,\pm1)\).

Lösung
\[\bar H = \frac{J}{4}\begin{pmatrix} -1 & 0 & 0 & 0\\ 0 & 1 & -2 & 0\\ 0 & -2 & 1 & 0\\ 0 & 0 & 0 & -1\end{pmatrix} \qquad \begin{matrix} \leftarrow |{\downarrow\downarrow}\rangle,\ n=0\\ \leftarrow |{\uparrow\downarrow}\rangle,\ n=1\\ \leftarrow |{\downarrow\uparrow}\rangle,\ n=2\\ \leftarrow |{\uparrow\uparrow}\rangle,\ n=3\end{matrix}\]

Mittlerer Block: Eigenwerte \(\tfrac J4(1\mp2)\).

\[\begin{aligned} \text{Singulett } \tfrac{1}{\sqrt2}\big(|{\uparrow\downarrow}\rangle - |{\downarrow\uparrow}\rangle\big):&\quad E = \boxed{\tfrac34 J}\\ \text{Triplett } |{\downarrow\downarrow}\rangle,\ \tfrac{1}{\sqrt2}\big(|{\uparrow\downarrow}\rangle + |{\downarrow\uparrow}\rangle\big),\ |{\uparrow\uparrow}\rangle:&\quad E = \boxed{-\tfrac14 J}\ \ \text{(dreifach)} \end{aligned}\]

Für \(J>0\) (ferromagnetisch) ist das Triplett der Grundzustand, für \(J<0\) das Singulett.

Dann numerisch, alle drei Cluster aus Aufgabe 1 
tri = [(1,2), (2,3), (3,1)]

Zweiter Test: Kronecker-Produkt

Unabhängige Kontrolle über den Weg i aus 2.2 S. 6: Spinoperatoren als Matrizen,

\[\bar H = -\sum_{ij\alpha} J^\alpha_{ij}\,\bar S^\alpha_i\bar S^\alpha_j,\qquad \bar S^\alpha_i = \mathbf{1}\otimes\cdots\otimes \underbrace{S^\alpha}_{\text{Platz } i}\otimes\cdots\otimes\mathbf{1}\]

Hier steckt die Lesefalle aus Szene 2: Platz 1 ist das niedrigste Bit und gehört deshalb im Kronecker-Produkt ganz nach rechts. In der Basis \((|{\downarrow}\rangle, |{\uparrow}\rangle)\) gilt

Lösung · Kronecker-Test
# Basis pro Platz: Index 0 = |↓> (z=0), Index 1 = |↑> (z=1)
Sz = np.diag([-0.5, 0.5])
Sx = np.array([[0, 0.5], [0.5, 0]])
Sy = np.array([[0, 0.5j], [-0.5j, 0]])       # aus S^+ = [[0,0],[1,0]]

def op(S, i, N):
    """S auf Platz i; Platz 1 steht ganz rechts im kron"""
    M = np.array([[1.0]])
    for k in range(N, 0, -1):
        M = np.kron(M, S if k == i else np.eye(2))
    return M

def H_kron(N, links):
    S = {'x': Sx, 'y': Sy, 'z': Sz}
    return -sum(J * op(S[a], p, N) @ op(S[a], q, N) for a, p, q, J in links)

# zufällige Kopplungen, alle Paare, N = 4
rng = np.random.default_rng(0)
L = [(a, p, q, rng.normal()) for a in 'xyz' for p in range(1,5) for q in range(p+1,5)]
print(np.allclose(hamilton_matrix(4, L), H_kron(4, L)))   # True

Ausblick: Wie voll ist die Matrix?

Tafel · 2.2 S. 9–10 \[\begin{aligned} &\text{höchstens}\quad \boxed{Z = L\cdot 2^N}\quad \text{Nicht-Null-Elemente}\\ &\text{Anteil}\quad \boxed{\gamma = \frac{Z}{2^N\cdot 2^N} = \frac{L}{2^N}}\\ &\text{Kitaev-Cluster: } L = \tfrac32 N\ \Rightarrow\ \gamma = \frac32\,\frac{N}{2^N}\ \to\ \text{„sparse matrix“}\\ &\text{volle Diagonalisierung: } T \sim \text{dim}^3 = 2^{3N} \end{aligned}\]
Frage
  1. Heisenberg-Dreieck: \(L=9,\ N=3\). Dann wäre \(\gamma = 9/8 > 1\). Wie passt das zusammen?
  2. Um welchen Faktor wächst die Rechenzeit, wenn du von \(N=10\) auf \(N=12\) gehst?
Lösung
  1. \(Z = L\cdot2^N\) ist nur eine obere Schranke (Skript: „the actual number … is lower“). Alle z-Links schreiben auf dieselben Diagonalelemente, und x- und y-Link landen auf demselben \((l,n)\) und heben sich teilweise auf. Tatsächlich sind es \(8+12 = 20\) von \(64\) Elementen.
  2. \(2^{3\cdot2} = 64\)-mal länger.
